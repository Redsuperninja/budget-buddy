# Changelog

## Unreleased
- Gift categories: **Mark as gift** now asks whether it's a gift to a charity or a personal gift (a present for someone). A charity gift moves the payment to a new **Charitable giving** category; a personal gift moves it to **Gifts** with no tax record. Both are "wants" categories Budget Buddy adds the first time.
- Donations from payments: on the Transactions page, **Mark as gift** turns a payment into a cash gift to charity, with the charity's name, the day you gave it and how much of the payment was the gift (for example, a $100 gala ticket where $60 was the gift). The gift shows on the Donations page with the paperwork to keep, the payment still counts as spending in its budget, and gifts can now be removed. An estimate, not tax advice.
- Tidier dashboard: five buttons along the top (Home, Money, Budget, Taxes, Phone) instead of twelve. Money, Budget and Taxes show their pages as tabs underneath, and old links to a page still work.
- Charts: the Home page shows bars for spending against each budget (by group and by category) and lines for the last 12 months of money in, spending and saving, with exact numbers when you point at a month. Every chart can switch to a table, and the colors work in light and dark mode and for color-blind readers.
- Safer caching: every reply from the Home Base's API now tells browsers (and the desktop app's window) never to keep a copy, so no financial data is left in a browser cache.
- Desktop app for Windows: Budget Buddy in its own window (no browser or Python needed), with a tray icon that can start with Windows and stays light until you open it. Closing the window stops Budget Buddy; your phone can sync while it's open. Everything you double-click (start, build and install the app) is now in the **launch** folder.
- Light and dark mode: the dashboard follows your computer's setting, and a **Colors** picker at the top lets you choose Light or Dark instead (remembered on this computer).
- Project rules: CI fails if test coverage drops (server 94%, dashboard logic 100%, phone 90/80/90/92%), a git hook stops pushes to `main` and its deletion from each computer, and the workflow guide explains how to merge stacked pull requests safely.
- Plans: Budget Buddy becomes a Windows app with its own window (no browser or Python install needed), with an optional light start at login that only fully starts when you open it (ADR-0008, proposed).
- Easy start on Windows: double-click **Start Budget Buddy** in the Budget Buddy folder. The first time it sets itself up; after that it starts in seconds and opens the dashboard, and if it's already running it just opens the dashboard. Close the window to stop.
- Plans: easy start (one start script, then a Windows shortcut and tray icon) moves up to next. Bank data goes free and open source first (ADR-0006): bank-file (OFX/QFX) import, then an auto-import folder, then an optional live connection using your own free developer account. A fuller phone app is planned in two steps, editing on the phone and then working without a computer (ADR-0007).
- Tax summary: record other deductions (medical bills, mortgage interest, property tax, IRA and HSA contributions, student loan interest, childcare and more), and see one page per tax year with your pay-stub totals, donations, stock gains and losses, and deductions by kind, each with a plain-English note on where it usually goes. Download it as a spreadsheet (CSV) for a tax preparer, or print it or save it as a PDF. An estimate, not tax advice.
- Suggested budget: a new dashboard page builds a 50/30/20 plan from your last three months. Needs keep what you really spend, savings aim for 20% (or what you already save), wants get what's left up to 30%, with plain-English notes when your numbers don't fit the guide. One click uses it as dollar amounts or as percentages of income.
- Saving by transfer: money you move from an everyday account into your own savings, investment, retirement or HSA account now counts as saved (once linked as a transfer), on the dashboard and on the phone. Moving it back out lowers the total; card and loan payments don't count.
- Percentage budgets: a category's budget can be a share of your income, like 15%, instead of a dollar amount. Percentages are worked out from a planned monthly income you can set (or from what actually came in that month), the Home page shows how much of each budget is used and what share of your income went to needs, wants and savings, and the phone gets the worked-out amounts.
- Auto-sort rules: tell Budget Buddy that a description containing some text (like "GROCERY MART") belongs in a category. New bank-file rows and transactions added without a category are sorted automatically, the longest matching text wins, a category you picked is never changed, and a "Sort transactions now" button sorts older transactions that have no category yet.
- Docs reorganized: `docs/guide/` is now a step-by-step user guide for people (with an index, tester pages, keeping your data safe, moving your data folder), and developer docs live in `docs/dev/` as small topic files; `docs/README.md` maps both.
- Project layout: the web dashboard now lives in its own top-level `dashboard/` folder, separate from the server and the phone app. The server serves it from a fixed list of files (or runs API-only without it), and it has its own tests and checks (ADR-0005).
- Code tidy-up: the pairing, bank CSV import and stocks code and the longest test files are split into smaller files with one job each; shared test helpers and one local-API helper for the scripts replace copied code. No behavior change.
- Project conventions: small single-purpose files and no copy-paste, for both code and docs (`docs/CONVENTIONS.md`); every agent brief now follows and checks them.
- Phone sync on the Home Base: a paired phone can now download a budget snapshot (this month's budget, recent transactions, accounts, tax totals), upload receipt photos, and report that it finished syncing. Everything is encrypted and each request works only once; removed phones are refused immediately. Photos are checked (JPEG, 3 MB, size in pixels) before they are saved encrypted, and a retried upload never creates a second copy. The phone app side comes later.
- Phone Home: Your accounts list shows all account kinds (checking, savings, credit card, loan, investment, other) with balances and money owed; budget.unassigned optionally shown as unsorted spending; gains tag notes possible wash sales.
- Phone sync client: encrypted health check, snapshot download, acknowledgment, and transport hardening (request size cap, host/port validation); Sync now button on Home and Settings tabs with Last synced timestamp; first sync runs automatically after pairing.
- Project workflow: leaner, more specialized AI agents (each uses a model matched to its job and replies briefly), and a clear note that the code is built by Claude and designed and reviewed by the project owner.
- Project scaffold: architecture, roadmap, ADRs, and specialized agent definitions.
- Home Base server skeleton: FastAPI app, settings, data folder, `/api/health`, home-network-only access, tests, and CI.
- Phone app starter: Expo app with bottom tabs (Home, Add Receipt, Taxes, Settings), light/dark theme, money formatting, and mobile CI.
- Server hardening: home-network check now also covers WebSockets, listens on this computer only by default, keeps the data folder private on macOS/Linux, and hides the API docs unless dev mode is on.
- Tax-year reference data for 2025 and 2026 (brackets, standard deduction, charitable, HSA, retirement, SALT, FICA limits) with IRS sources and a validating loader. See `docs/tax-data.md`.
- Database layer: SQLite database in the data folder with tables for accounts, transactions, categories, paychecks, receipts, donations, stocks, deductions, and devices; it sets itself up and updates automatically on start, comes with a starter set of budget categories, and stores all money as whole cents.
- Sync API contract v1: the exact rules for how the phone and the computer pair and sync, with test examples both sides can check (ADR-0004).
- Encryption at rest: account numbers, notes, and receipt file names are encrypted in the database, receipt photos can be saved encrypted, the key lives in Windows Credential Manager (or the macOS/Linux equivalent), and a recovery phrase lets you get your data back if that key is lost (ADR-0003).
- Accounts + transactions API for the computer-side dashboard (`/api/local/...`, this computer only): add, edit, and remove accounts and transactions, see account balances, filter and page through transactions, and link transfers between your own accounts. Errors come back as plain-English messages. Other websites open in your browser can't reach it (Host and Origin checks), every route except the phone's is this-computer-only by default, search text stays out of the logs, and transfers, refunds and opening balances follow fixed rules so they never turn into surprise income or spending.
- Phone Home dashboard: this month's income, spending, what's left, and savings rate; Needs / Wants / Savings bars you can tap to see categories; recent activity; and a Taxes summary. Shows clearly labeled sample data until the phone is connected.
- Categories and monthly summary for the computer-side dashboard: list, add, rename, and set a monthly budget for categories, plus a per-month view of income, spending, and savings that leaves out transfers and balance adjustments (like opening balances) and nets refunds against spending. Money moved to your own savings account isn't counted here yet. Budgets apply to every month. Changing one also changes what past months show.
- Bank CSV import: load your bank's CSV download into an account. Budget Buddy spots the date, description and amount columns (or separate money-out/money-in columns), copes with `$` signs, commas, `(12.34)` negatives, different date styles, header lines and file encodings, and lets you flip the signs for credit cards. You see a preview first, re-importing an overlapping statement skips rows already there, and the column choices can be saved per account so next time is one click. Files are capped at 5 MB / 10,000 rows, and nothing from the file is written to the logs.
- Paychecks API (`/api/local/paychecks`, this computer only): enter, edit, and remove paychecks with every pay-stub line (taxes, before-tax and after-tax deductions), checked to add up to the cent; link a paycheck to its bank deposit without counting the money twice; and see year-to-date totals with a check for too much Social Security withheld. See `docs/paychecks.md`.
- Receipts API for the computer-side dashboard (`/api/local/receipts`, this computer only): add, edit, and remove receipts (shop, date, total, category, linked transaction, encrypted notes) and attach a photo. Photos must really be JPEG, PNG or HEIC (checked from the file itself) and at most 3 MB; location and camera details are removed from JPEG and PNG photos; photos are encrypted on disk and deleted along with their receipt. Reading text from photos (OCR) comes later.
- Charitable donations: add, edit, and remove cash and goods donations (optionally linked to a receipt), and see a yearly summary that totals your gifts and tells you what proof to keep, such as a written acknowledgment for gifts of $250 or more, Form 8283 when goods add up to more than $500, and an appraisal for items worth more than $5,000. The amounts come from each tax year's data file, and the summary is an estimate, not tax advice.
- Phone pairing screen: scan the code from your computer (or type it in) to connect, with plain-English help if something goes wrong; Settings has a Connect button, and the phone's keys are kept in its secure storage.
- Phone pairing on the computer side: "Pair a phone" makes a one-time code (QR or pasteable text) that expires after 10 minutes and works once, the phone and computer agree on a private key without it ever appearing in the QR, paired phones are listed, and Remove stops a phone from working right away.
- Stocks: record purchases (symbol, date, shares, total cost with fees) and sales (shares and money received after fees) at `/api/local/stocks/...`. Sales use your oldest shares first (FIFO), including part of a purchase; each part is marked short term (held one year or less) or long term, counting from the day after you bought; possible wash sales are flagged without changing the numbers; and a yearly summary totals short- and long-term gains. Selling more shares than you owned gets a plain-English error, and every result is labeled an estimate, not tax advice.
- User-testing kit: Windows scripts to set up, start a separate test Home Base (its own data folder and port), load made-up demo data, show a pairing QR code for a test phone, start the phone app, and preview and import a sample bank CSV. Plus a tester guide (`docs/TESTING.md`), a feedback issue template, and a milestone plan in the roadmap.
- Local web dashboard at `http://127.0.0.1:<port>/` served by the Home Base: Home, Accounts, Transactions, Categories, Import bank file, Connect phone (QR drawn on the computer, countdown, polls devices, Remove), Paychecks, Donations, Stocks. Vanilla JS modules (no build, no internet requests). Security: CSRF token in X-CSRF-Token with Origin and Host checks on writes, strict CSP, nosniff/CORP on all responses, static files from an allowlist. Closes #4.
