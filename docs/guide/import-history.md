# Import history: see and remove imported files

Every file you import (a bank file, stock trades, a brokerage activity file or a positions file) is listed under
**Money**, **Import history** (in the [All tools](open-the-dashboard.md#simple-view-or-all-tools) view), newest first: when you imported it, what kind of file it was, the account, the file's
name and how much it added. Importing a file that adds nothing new isn't listed.

## Remove an outdated or wrong import

Click **Remove** next to it and confirm. Everything that file added is deleted:

- **Transactions** it added go. A transfer it was part of goes back to a normal transaction on the other side, a
  paycheck or gift linked to one of its deposits stays but loses that link, and its dividends go.
- **Stock trades** it added go, and your other sales are matched again, oldest shares first. If a sale you added
  some other way needs shares from this file, Budget Buddy says so and removes nothing: delete that sale first.
- **Positions** it added go (a newer positions file for the same account already replaces the older one).

Your other data stays. To bring the file back, import it again.
