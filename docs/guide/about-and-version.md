# Find your version, the privacy statement and the licences

Open **Settings** (top right of any page), then **About**. You will see:

- **The version** of Budget Buddy, for example "Budget Buddy version 0.1.0". Tell us this number if you ask for help.
- Links to the **user guide**, the **privacy statement** (what Budget Buddy keeps and where), the **security policy**
  (how to report a problem privately) and the **licences** (Budget Buddy's own, and those of the libraries it uses).

The links open Budget Buddy's pages on GitHub, so they need the internet. Everything else in Budget Buddy works
without it. In the Windows app they open in your usual web browser, and the Budget Buddy window stays where it is.
This works the same in a phone's web browser. The Windows download also has the licences as files
(`LICENSE` and `THIRD-PARTY-NOTICES.txt`).
