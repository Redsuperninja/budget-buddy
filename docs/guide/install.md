# Download and install Budget Buddy (Windows)

The easiest way to get Budget Buddy: one download, no Python, no setup.

## Install

1. Go to the project's **Releases** page on GitHub and download `Budget-Buddy-<version>-Windows.zip` (under
   **Assets**).
2. Right-click the zip and choose **Extract All...**. (Installing straight from inside the zip won't work.)
3. In the unzipped folder, double-click **Install Budget Buddy**. A window shows what it's doing; it takes about a
   minute and needs no admin rights.
4. Open **Budget Buddy** from the Start menu or the desktop shortcut.

**"Windows protected your PC"?** This early version isn't signed by a publisher yet, so Windows asks the first time.
Click **More info**, then **Run anyway**. Only do this for a copy from the project's own Releases page.

To try Budget Buddy without installing, open the **Budget Buddy** folder inside the unzipped folder and double-click
**Budget Buddy.exe**.

## First steps

Budget Buddy opens on **Home** with a **Get started** list: add your accounts, bring in what you spent, and set
monthly budgets, then save your recovery phrase and make a backup. Each step links to the page that does it. It starts in the simple view; for every tool, open
**Settings** at the top right and set **View** to **All tools** ([more](open-the-dashboard.md#simple-view-or-all-tools)).

Write down your recovery phrase and keep it safe ([keep your data safe](keep-your-data-safe.md)).

## On your phone

There's nothing to install on your phone: open Budget Buddy in its web browser at home
([how](use-on-another-computer.md)).

## Update

Close Budget Buddy (and choose **Quit** on its tray icon), download and unzip the new version, and double-click
**Install Budget Buddy** again. Your data is kept.

## Remove

Open Windows **Settings**, **Apps**, find **Budget Buddy** and click **Uninstall** (or double-click **Uninstall
Budget Buddy** in the unzipped folder). The app, its shortcuts and "Start with Windows" are removed. Your data
folder (`%LOCALAPPDATA%\BudgetBuddy`) is kept, in case you install again; delete it yourself only if you never want
your records back.

## Something went wrong?

| What you see | What to do |
| --- | --- |
| "Budget Buddy.exe wasn't found" | Extract the whole zip first (step 2), then run **Install Budget Buddy** from the unzipped folder. |
| "Budget Buddy is running" | Close its window, right-click the tray icon and choose **Quit**, then try again. |
| It won't open after an update | An older Budget Buddy can't open data saved by a newer one. Install the newest version. |
