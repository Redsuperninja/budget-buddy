# Move your data folder

If Budget Buddy warns that your data folder is in a place you don't want it, you can move it to a safer location.

## When to move your data folder

Budget Buddy warns you if your data folder is:
- Inside a code project folder (like the Budget Buddy source)
- Inside a cloud-synced folder (OneDrive, Dropbox, iCloud, Google Drive, Box, pCloud, Nextcloud)
- On a Mac, the Desktop or Documents (if "Desktop & Documents Folders" are synced to iCloud)

## How to move it

1. Close Budget Buddy on your computer
2. Move the whole data folder to a place that isn't synced. Examples:
   - Windows: `C:\BudgetBuddyData` or a folder in your home folder
   - macOS/Linux: a folder in your home directory (not Desktop or Documents if iCloud syncs them)
3. Tell Budget Buddy where the folder is now by setting the data folder location (ask whoever set up Budget Buddy)
4. Start Budget Buddy again

Your encryption key stays in this computer's password vault, so it still works after the move.

## Something went wrong?

**Budget Buddy won't start after moving the folder**

Make sure:
- The folder path is set correctly (ask whoever set up Budget Buddy)
- Budget Buddy is running on the same computer where the folder lives
- You moved the entire folder, not just copied it

**Budget Buddy can't find the folder**

Stop Budget Buddy, check that the folder is where you moved it, and make sure the path is set correctly.
