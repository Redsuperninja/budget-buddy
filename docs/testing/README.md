# Trying Budget Buddy out: for testers

For people trying early versions of Budget Buddy with made-up data, kept apart from any real data. Using Budget
Buddy for your own money? See the [guide](../guide/README.md) instead.

1. [Set up for testing](set-up-for-testing.md) — Install Python, Node and Expo Go; run the setup script; add a firewall rule (first time only).
2. [Start a test session](start-a-test-session.md) — Open three windows; load demo data; start your phone app.
3. [Open the dashboard](../guide/open-the-dashboard.md) — What you'll see; the tabs along the top; where to type the address.
4. [What to test](what-to-test.md) — What's ready; the checklist; how to report bugs.
