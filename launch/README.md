# launch

Everything you double-click to use Budget Buddy on Windows. (The code behind each one is in `scripts/`.)

| Double-click | What it does |
| --- | --- |
| **Start Budget Buddy** | Starts Budget Buddy from this folder and opens it in your web browser. Sets itself up the first time. Close its window to stop. |
| **Build desktop app** | Makes the Windows app, **Budget Buddy.exe**, in the `Budget Buddy` folder here. Takes a few minutes. |
| **Install desktop app** | Installs the built app for you, with Start menu and desktop shortcuts. |
| `Budget Buddy\Budget Buddy.exe` | The app itself, once built: Budget Buddy in its own window, with a tray icon. |

Guides: [Start Budget Buddy](../docs/guide/start-budget-buddy.md) and
[The desktop app](../docs/guide/desktop-app.md).
