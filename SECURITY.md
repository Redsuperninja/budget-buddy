# Security policy

## Supported versions

We fix security problems in the 0.1.x releases. Install the newest 0.1.x release from the Releases page on GitHub.

## Report a problem privately

Please don't post security problems as public issues, pull requests or discussions. Report them privately:

1. Open this repository on GitHub.
2. Click the **Security** tab.
3. Click **Report a vulnerability**.
4. Describe the problem (see the list below) and send it.

Only you and the repository owner can see the report.

## What to include

- What you found, and which page or feature it's on
- The steps to make it happen
- What you think someone could see or do because of it
- The version number of the release you're using

Please use made-up data in your steps. Don't send real bank details, real amounts or your real budget.

## What happens next

We aim to reply within 7 days.

## Something went wrong?

- **You can't see "Report a vulnerability".** Private reporting isn't turned on yet. Don't post the details publicly. Check again later.
